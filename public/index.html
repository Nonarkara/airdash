เรียลไทม์เท่าที่ระบบจะทำได้ — ข้อมูลอาจมีข้อผิดพลาดจากระบบรับสัญญาณ โปรดใช้วิจารณญาณในการตัดสินใจ เราพยายามอย่างสุดความสามารถเพื่อคำนวณจากข้อมูลที่ดีที่สุดที่มีอยู่ ณ ขณะนั้น Real-time as the system allows. Data may have reception issues, so use judgement in any decision. We work as hard as we can to compute from the best data available at the moment.
มาตรฐานระบบ · 7 แหล่งข้อมูลสด · ดึงทุก 10 นาที–3 ชม. · สถานีเฝ้าระวัง 4,400+ แห่ง · 0 ข้อมูลจำลอง · ทุกค่าถูกบันทึกลง SQLite เพื่อตรวจสอบย้อนหลัง System standards · 7 live data sources · refreshed every 10 min–3 h · 4,400+ monitored stations · 0 mock data · every reading persisted to SQLite for full audit trail
แก่นของระบบนี้ · คำนวณจากข้อมูลที่ดีที่สุดที่หาได้ เพื่อหาแนวทางปกป้องสุขภาพและรักษาชีวิต — นี่คือเป้าหมายสูงสุดของ AirDash Core idea of this system · compute from the best data we can find, to map out the possibilities of protecting health and saving lives — that is AirDash's highest goal.

ดร.นน อัครประเสริฐกุล
Dr Non Arkaraprasertkul
ผู้เชี่ยวชาญอาวุโส ฝ่ายส่งเสริมเมืองอัจฉริยะ สำนักงานส่งเสริมเศรษฐกิจดิจิทัล (depa)
ผู้ริเริ่มและดูแลโครงการ AirDash — ระบบเฝ้าระวังฝุ่น PM2.5 และคุณภาพอากาศเรียลไทม์สำหรับประเทศไทย เพื่อให้ทุกจังหวัดเข้าถึงข้อมูลสถานการณ์ฝุ่นจากแหล่งข้อมูลภาครัฐได้อย่างโปร่งใส ผ่านสำนักงานเมืองอัจฉริยะประเทศไทย (Smart City Thailand Office)
