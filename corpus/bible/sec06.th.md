# 6. การระบายอากาศและภาวะอากาศนิ่ง

สองจังหวัดอาจปล่อยควันเท่ากันแต่จบวันด้วยอากาศที่ต่างกันลิบลับ ความต่างอยู่ที่การระบายอากาศ — ความสามารถของบรรยากาศในการเจือจางและกำจัดสิ่งที่ถูกปล่อยเข้าไป AirDash เข้ารหัสแนวคิดนี้เป็น **คะแนนย่อยภาวะอากาศนิ่ง (stagnation)** ซึ่งมีน้ำหนัก 15% ของคะแนนเฝ้าระวังอากาศ บทนี้อธิบายอุตุนิยมวิทยาที่อยู่เบื้องหลัง

## 6.1 แนวคิดเรื่องการระบายอากาศ

ลองนึกถึงอากาศเหนือเมืองเป็นกล่องใบหนึ่ง พื้นกล่องคือพื้นดิน ฝากล่องคือ **ความสูงชั้นผสม (mixing height)** — ระดับความสูงที่อากาศผิวพื้นพาความร้อนและผสมกันได้อย่างอิสระ ส่วนผนังข้างถูกเปิดโดย **ลม** ซึ่งพัดพาสิ่งที่อยู่ในกล่องออกไปแล้วแทนที่ด้วยอากาศที่สะอาดกว่า ผลคูณของความเร็วลมกับความสูงชั้นผสมมักถูกเรียกว่าสัมประสิทธิ์การระบายอากาศ: กล่องที่ลึกและมีลมโกรกเจือจางมลพิษได้มหาศาล ขณะที่กล่องตื้นและนิ่งกลับทำให้มันเข้มข้นขึ้น ความเข้มข้นคือการปล่อยหารด้วยการระบาย — การระบายที่ลดลงครึ่งหนึ่งจึงส่งผลต่ออากาศเท่ากับการเพิ่มทุกแหล่งกำเนิดเป็นสองเท่า

## 6.2 นิ่งบวกแห้งเท่ากับสะสม

รูปแบบที่อันตรายคือการเกิดพร้อมกัน ในคืนฤดูหนาวที่ฟ้าใส พื้นดินเย็นตัวลง ชั้นผกผันผิวพื้นกดฝากล่องลงมาที่ระดับหลังคาบ้าน แล้วจราจรยามเช้าบวกการเผาข้ามคืนก็เทมลพิษเข้าไปในชั้นอากาศที่ถูกฝาล็อกไว้ — นี่คือเหตุที่เช้าวันหมอกควันทั้งดูและวัดค่าได้แย่ที่สุด ก่อนแดดบ่ายจะยกความสูงชั้นผสมขึ้น ถ้าลมยังอ่อนอยู่ แต่ละวันจะเริ่มจากจุดที่วันก่อนทิ้งไว้ และถ้าไม่มีฝนกำลังมา กระบวนการเดียวที่จะรีเซ็ตการสะสมได้ — การชะล้าง — ก็หายไปด้วย นิ่ง แห้ง และเย็น คือสูตรของเหตุการณ์ฝุ่นต่อเนื่องหลายวันแม้การเผาไม่เพิ่มขึ้นเลย

## 6.3 คะแนนย่อยภาวะอากาศนิ่ง

เครื่องยนต์สร้างคะแนนย่อยจากลมพยากรณ์และโอกาสฝนของจังหวัด:

```
wind < 8 km/h → 70 · < 12 → 45 · < 16 → 20 · else 0
+30 if rain probability (24 h) < 20% · +15 if < 40%
forced to 0 if observed rain in the last 24 h exceeds 10 mm
```

พจน์ลมอ่านความสามารถในการกระจายมลพิษ พจน์โอกาสฝนอ่านว่าการบรรเทาด้วยการชะล้างเป็นไปได้แค่ไหน และฝนหนักที่วัดได้จริงจะล้างคะแนนทั้งก้อนเป็นศูนย์ เพราะบรรยากาศที่กำลังชะล้างตัวเองอยู่ย่อมไม่ใช่บรรยากาศนิ่งโดยนิยาม ผลลัพธ์ถูกจำกัดไว้ที่ 0–100 มันตั้งใจเป็น *ตัวแทน (proxy)*: AirDash ไม่ได้จำลองความสูงชั้นผสมโดยตรง — ข้อมูลระดับบอลลูนตรวจอากาศไม่มีให้รายจังหวัดแบบเรียลไทม์ — ลมผิวพื้นพยากรณ์กับโอกาสฝนจึงยืนแทนภาพการระบายอากาศฉบับเต็ม ตัวแทนนี้คู่ควรกับน้ำหนัก 15% ของมัน เพราะเป็นองค์ประกอบที่อธิบายว่าทำไมการปล่อยมลพิษเท่ากันจึงเจ็บกว่าในเดือนมกราคมเมื่อเทียบกับกรกฎาคม
