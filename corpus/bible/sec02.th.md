# 2. แหล่งข้อมูล: บัญชีรายการทั้งหมด

ระบบเฝ้าระวังคุณภาพอากาศน่าเชื่อถือได้ก็ต่อเมื่อฟีดที่อยู่เบื้องหลังมันน่าเชื่อถือเท่านั้น AirDash ใช้เฉพาะแหล่งข้อมูลสาธารณะแบบเปิด ไม่ต้องใช้คีย์ (หรือใช้คีย์ฟรี) ดึงเข้ามาโดยตัวจัดตารางงานหนึ่งตัว แล้วบันทึกลง SQLite เพื่อให้ตัวเลขทุกตัวบนหน้าจอย้อนกลับไปหา URL ต้นทางและเวลาที่สังเกตได้

บทนี้แบ่งเป็นสองส่วน **2.1–2.4** บัญชีสิ่งที่ AirDash ดึงและแสดงจริงในวันนี้ — สิบเก้าแหล่งที่หมุนเวียนดึงข้อมูล และชั้นแผนที่ที่ทำงานฝั่งผู้ใช้ พร้อมรอบเวลาและข้อควรระวังของแต่ละรายการ ส่วน **2.5** บันทึกแหล่งข้อมูลที่เราสำรวจ เอาไปทดสอบ แล้ว **ตัดสินใจไม่นำมาใช้** พร้อมเหตุผล รายการที่สองนี้สำคัญกว่าที่จะได้ของดี: บัญชีแหล่งข้อมูลที่มีแต่ของที่ใช้ได้ อ่านแล้วเหมือนเป็นคำอ้างว่าปัญหาแก้จบแล้ว ซึ่งไม่จริง

### 2.1.1 ทำไม DustBoy จึงสำคัญเกินกว่าจะดูจากจำนวนสถานี

สถานีราว 200 แห่งของ Air4Thai มากพอสำหรับความครอบคลุมระดับประเทศ แต่แทบไม่มีประโยชน์สำหรับภาคเหนือ ฤดูไฟไหม้ภาคเหนือจะผันผวนไปตามคำถามว่าลุ่มน้ำแม่มอบและแนวสันดอยสุเทพ–ดอยอินทนนทนอยู่ใต้หมอกควันหรือไม่ และ พก. มีสถานีกำกับดูแลเพียงไม่กี่แห่งต่อพื้นที่เท่าหลายจังหวัด DustBoy คือเครือข่ายเซ็นเซอร์ราคาถูกที่มหาวิทยาลัยเชียงใหม่ตั้งขึ้นเพื่อตอบคำถามนี้โดยเฉพาะ ในความละเอียดที่ พก. ไม่มีทางทำตามได้

นอกจากนี้ DustBoy ยังเป็นคู่ที่เหมาะสมของงานดาวเทียม AOD ให้ความครอบคลุมในพื้นที่ที่ไม่มีเซ็นเซอร์ ส่วน DustBoy ให้ความจริงภาคพื้นดินที่ใช้แปลง AOD ให้เป็นค่าประมาณ PM2.5 ระดับพื้นผิว วันนี้ `/api/smoke` บอกได้ว่ามีไฟไหม้พัดลมเหนือ และ `/api/forecast` บอกได้ว่าแบบจำลองคาดว่าจะแย่ลง แต่สิ่งเดียวที่บอกว่าอากาศในภาคเหนือ **เป็นอย่างไรจริง ๆ** ก็คือคะแนนระดับจังหวัดเท่านั้น DustBoy ปิดช่องว่างนี้ในระดับตำบล

API เปิดและใช้ฟรีที่ `https://open-api.cmuccdc.org/` — ลงทะเบียนเท่านั้น ไม่มีค่าใช้จ่าย ไม่ต้องมีข้อตกลงกับสถาบัน ทุก endpoint ใช้โทเคนแบบ `Authorization: Bearer` โค้ดของแหล่งนี้เขียนและรออยู่แล้ว ต้องการเพียงคีย์ที่เจ้าของระบบเป็นผู้ขอเท่านั้น

## 2.2 ชั้นแผนที่ที่ทำงานฝั่งผู้ใช้

ทั้งหมดนี้เป็นบริการไทล์ที่เบราว์เซอร์ดึงตรง ๆ และไม่เคยถูกจัดเก็บ ชั้นจาก NASA GIBS ช้ากว่าการประมวลผลของตัวเองหนึ่งวันปฏิทิน ส่วนชั้นจากดาวคงที่เป็นข้อมูลสด

- **ละอองลอยและควัน:** AOD รวมจาก MODIS (Terra+Aqua), AOD ความละเอียด 3 กม. ของ Aqua และ Terra, ดัชนีควัน UV จาก OMPS, ดัชนี PyroCb จาก OMPS (ควันชั้นสูง สัญญาณควันข้ามพรมแดน), ดัชนีควัน UV จาก OMI, AOD ย่าน 388 นาโนเมตรจาก OMI, ค่า single scattering albedo ของ OMI (ตัวแยกควันออกจากซัลเฟต), ชนิดละอองลอยจาก VIIRS NOAA-20 (ควันเทียบฝุ่นเทียบละอองเกลือทะเล) และคะแนนฝุ่นจาก AIRS L2
- **การพาหล: คาร์บอนมอนอกไซด์ที่ 500 hPa จาก AIRS — ควันที่ลอยสูงแล้วกำลังเคลื่อนที่
- **แก๊สภูเขาไฟและอุตสาหกรรม:** SO2 จาก OMPS NOAA-20 ที่ชั้นกลางบรรยากาศและที่ระดับพื้นผิว
- **ฝนและเมฆ:** ฝน GPM IMERG เรียลไทม์, Himawari-9 อินฟราเรด และค่าความหนาละอองลอยจาก JAXA Himawari-9 สดทุก 10 นาที
- **ภาพสีจริงและแสงกลางคืน:** ภาพสะท้อนแสงแก้ไขจาก MODIS Terra และค่าความส่องสว่างจาก VIIRS Day/Night Band — อันหลังแสดงการเผาเกษตรตอนเย็นและการกระจายเป็นหมอกนวลของเมืองใต้หมอกควัน
- **เรดาร์และกล้อง:** เรดาร์ฝนของไทย และกล้อง CCTV สาธารณะ 1,385 ตัว ซึ่งสีของหมุดคือค่า PM2.5 ของสถานีที่ใกล้ที่สุด

## 2.3 การอ่านหมอกควันจากภาพกล้อง

AirDash ย่อภาพกล้องสดหนึ่งภาพให้เหลือชุดคุณลักษณะเชิงค่าคงที่ และคะแนนคัดกรองเบื้องต้น ฐานทางกายภาพคือคอนทราสต์จางลงตามระยะทางแบบเอกซ์โพเนนเชียล ด้วยอัตราที่บรรยากาศกำหนด — ความสัมพันธ์ของคอสช์มีเดอร์ `C(x) = C₀·e^(−βx)` โดยช่วงการมองเห็น `V = 3/β`

นี่เป็นการ **ไม่** ใช้โมเดลการลบหมอกด้วยโครงข่ายประสาทอย่างตั้งใจ งานวิจัยที่ตีพิมพ์เกี่ยวกับการประเมินทัศนวิสัยจากกล้อง (Babari et al. 2011, *Atmospheric Environment* 45:5316) ได้ fit สัมประสิทธิ์แยกเป็นรายกล้องเทียบกับเครื่องมาตรวัดอ้างอิง และไม่มีชุดโค้ดเปิดของวิธีนั้นเลย โมเดลลบหมอกให้ภาพที่สวยขึ้น ไม่ใช่ตัวเลข และภาพที่สวยขึ้นไม่มีค่าอะไรกับผลิตภัณฑ์ข้อมูล คุณลักษณะเหล่านี้คำนวณด้วย CPU ในระดับไมโครวินาที ขณะที่โครงข่ายขนาดเล็กหนึ่งตัวจะใช้เวลาหลายร้อยมิลลิวินาทีต่อภาพ — ต่างกันพันเท่าเมื่อคูณด้วยกล้อง 1,385 ตัว

มีข้อจำกัดสามข้อที่ต้องพูดตรง ๆ

- **ไม่มีการอ้างตัวเลขกิโลเมตร** การมองเห็นเชิงสัมบูรณ์ต้องการระยะจากกล้องถึงวัตถุ และไม่มีใครเผยแพร่เรขาคณิตของกล้องเทศบาล สิ่งที่ระบบผลิตคือดัชนีหมอกควันแบบสัมพัทธ์เทียบกับกล้องแต่ละตัว
- **กล้องในเมืองคือกรณีแย่ที่สุด** วิธีของ Babari ตั้งสมมติฐานว่ามีการกระจายของระยะวัตถุอย่างต่อเนื่อง กล้องจราจรที่หันไปตามถนนที่มีตึกสูงตั้งอยู่ละเมิดสมมติฐานนั้น และผู้เขียนเองก็ระบุไว้ กล้องริมถนนเปิดและกล้องที่นครศรีธรรมราชเหมาะกับวิธีนี้กว่า
- **คะแนนถูกไม่ให้ ไม่ใช่เดา** เมื่อภาพไม่มีโครงสร้างที่ใช้ได้ ระบบจะคืนค่า null พร้อมเหตุผล แทนที่จะคืนศูนย์อย่างมั่นใจ

คุณลักษณะเหล่านี้ถูกจัดเก็บคู่กับค่า PM2.5 ภาคพื้นดิน เพื่อให้สามารถ *สอบเทียบ* ได้เมื่อมีเหตุหมอกควันจริงเกิดขึ้นแล้ว ตัวฟิตจะปฏิเสธการทำงานหากค่าเป้าหมายไม่เปลี่ยนแปลงจริงและความสัมพันธ์ไม่แข็งแรงพอ และจะรายงานแยกต่างหากว่าความแปรปรวนที่พบมาจากความต่างระหว่างกล้องมากกว่าภายในกล้องหรือไม่ — เพราะการ fit รวมทุกกล้องที่อธิบายได้แต่คำถามว่า "นี่คือกล้องตัวไหน" ไม่ได้กำลังวัดอากาศ

## 2.4 ข้อควรระวังสำหรับผู้อ่าน

- **สถานีภาคพื้นดินเบาบางในบางจังหวัด** จังหวัดที่มีสถานีเดียวก็ถูกให้คะแนนจากสถานีเดียว แดชบอร์ดแสดงจำนวนสถานีตรง ๆ แทนที่จะซ่อนไว้ จังหวัดแปดแห่งที่เซ็นเซอร์เงียบไปตอนนี้ใช้ค่าประมาณจากดาวเทียมที่มีป้ายกำกับชัดเจน
- **การพยากรณ์คือแบบจำลอง** ผลิตภัณฑ์ CAMS เป็นแบบจำลองระดับโลกที่มีอคติที่รู้กันดีในเอเชียตะวันออกเฉียงใต้ช่วงไฟไหม้หนัก AirDash ใช้การปรับอคติรายจังหวัดที่เรียนรู้จากค่าภาคพื้นดิน และจำกัดช่วงของการปรับ — การพยากรณ์ที่ปรับเกินหรือขาดการปรับแย่กว่าการไม่ปรับเลย การพยากรณ์เป็นเพียงหนึ่งในห้าปัจจัย ไม่ใช่ความจริง
- **รอบเวลาไม่ใช่ความหน่วง** สถานีที่อัปเดตทุกชั่วโมงอาจเผยแพร่ค่าที่เก่ากว่านั้นไปแล้วหนึ่งชั่วโมง เวลาที่แสดงคือเวลาสังเกตจากต้นทาง และกลไกให้คะแนนจะทิ้งค่าที่เก่ากว่าหน้าต่างความสดของมัน แทนที่จะเอาไปใช้ซ้ำอย่างเงียบ ๆ
- **ฟีดข่าวมาจากการกรองคำสำคัญ** ไม่ใช่การคัดสรร มีไว้เพื่อให้เห็นการกระโดดบนแผนที่และพาดหัวข่าวเคียงกัน
- **AOD จากดาวเทียมหายไปพอดีในที่ที่ต้องการ** ทั้งเมฆและหมอกควันเองลดการดึงค่าด้วยแสง ดังนั้นรูโหว่ของ AOD จะกระจุกตัวอยู่เหนือช่วงที่แย่ที่สุด นี่คือเหตุผลที่สถานีภาคพื้นดิน ไม่ใช่ดาวเทียม ยังคงเป็นมาตรฐานอ้างอิง

## 2.5 แหล่งที่สำรวจ ทดสอบ และตัดสินใจไม่นำมาใช้

การบันทึกส่วนนี้สำคัญกว่าการไล่บอกความสำเร็จ แต่ละรายการถูกทดสอบโดยตรงเมื่อวันที่ 2026-09-28 เว้นแต่ระบุไว้ "เข้าไม่ถึง" หมายความว่าชื่อโดเมนไม่มีบันทึก DNS ชนิด A ซึ่งเป็นข้อเท็จจริงของเซิร์ฟเวอร์ปลายทาง ไม่ใช่ข้อจำกัดของเครือข่ายเรา

| แหล่ง | สถานะ | เหตุผลที่ไม่นำมาใช้ |
|---|---|---|
| พอร์ทัลหมอกควันอาเซียน ASMC (`haze.asean.org`) | เข้าไม่ถึง | NXDOMAIN — โดเมนไม่เผยแพร่บันทึก A เป็นตัวเลือกที่เหมาะที่สุดสำหรับข้ามพรมแดน คือรายงานจุดไฟรายวันของอาเซียนและแบบจำลองการกระจาย PM10 24 ชม. |
| SatPM2.5, Washington University ACAG | เข้าไม่ถึง | `satepsanone.ecs.wustl.edu` เป็น NXDOMAIN เป็นผลิตภัณฑ์ PM2.5 ที่ผ่านการทดสอบโดยวิชาการและผสมดาวเทียมกับแบบจำลองกับสถานีวัด จึงเป็นการสูญเสียที่แท้จริง |
| GEMS (GEO-KOMPSAT-2B) AOD รายชั่วโมง | ไม่มีแบบไม่ต้องใช้คีย์ | AOD กลางวันรายชั่วโมงเหนือเอเชียตะวันออกเฉียงใต้คือสิ่งเดียวที่ควรเพิ่มมากที่สุดสำหรับติดตามหมอกควันในรอบวัน จัดทำโดย NIER ของเกาหลีผ่าน SFTP โดยต้องสมัคร ไม่ได้อยู่บน NASA GIBS — ทดลอง `GEMS_Aerosol_Optical_Depth` และชื่ออื่น ๆ บน GIBS ได้ผล HTTP 400 ทั้งหมด ควรพิจารณาสมัคร |
| MAIAC 1 กม. AOD (MODIS) | ต้องใช้ Earthdata token | ความละเอียดสูงกว่า Deep Blue สำหรับการประมาณ PM มีใน NASA LANCE/LAADS ด้วย Earthdata Login ฟรี เพิ่มเป็นแหล่งที่ใช้โทเคนได้เหมือนที่ IMERG ทำ |
| OpenAQ v3 | ต้องใช้ API key | รวบรวมสถานี พก. ชุดเดียวกับที่ AirDash ดึงตรง ๆ อยู่แล้ว จึงเพิ่มความครอบคลุมเฉพาะในประเทศเพื่อนบ้าน ซึ่งก็ยังบางอยู่ |
| WAQI | ต้องใช้โทเคน เป็นข้อมูลจากชุมชน | เซ็นเซอร์ระดับคุณภาพที่ไม่แน่นอน ไม่ใช่ข้อมูลที่เหมาะกับผลิตภัณฑ์สาธารณะด้านสุขภาพที่มีเครือข่ายทางการอยู่แล้ว |
| SERVIR AQ Tracker | ตัวอย่างอ้างอิง ไม่ใช่แหล่งข้อมูล | เป็นแพลตฟอร์มสำเร็จรูป ไม่ใช่ฟีด เป็นประโยชน์ในฐานะจุดตรวจเทียบแบบจำลองควันของเรา |
| Envi Link (BDI Thailand) | ตัวอย่างอ้างอิง ไม่ใช่แหล่งข้อมูล | แพลตฟอร์มรวมข้อมูลระดับชาติกว่า 200 ชุด รวมถึงไฟล์นำร้องเชียงใหม่ ควรอ่านเพื่อดูวิธีนำเสนอ PM2.5 ส่วนฟีดเบื้องหลังคือสิ่งที่เรามีอยู่แล้ว |
| Global PM2.5 Watch (World Bank) | ไม่ได้นำมาใช้ | ค่าประมาณรายเมืองจากแมชเลิร์นน์รายวัน ใช้ยืนยันเพิ่มเติมได้อย่างเดียว และตัวเลขจากแบบจำลองที่วางข้างตัวเลขที่วัดจริงทำให้สับสน |

ทุกสิ่งที่จัดเก็บส่งออกได้: ค่าดิบถูกเก็บไว้บน SSD เป็นหน้าต่างแบบเลื่อน และถูกเก็บถาวรไว้ในไดรฟ์ภายนอก และชุดข้อมูลเต็มส่งออกเป็น CSV ได้จาก endpoint ส่งออก
