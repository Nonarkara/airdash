# Corrected draft v2 — 4 November 2026

This version supersedes v1. It remains a developer-led preprint, not peer reviewed.
All-author approval, contributions and funding declarations remain pending.

- Withdraws alert-to-Telegram hand-off and simulated end-to-end latency claims.
  The available calculation matches an alert to the next broadcast log timestamp;
  it does not establish batch membership, successful acceptance or device delivery.
- Withdraws daily alert hit percentages whose denominators counted missing daily
  outcomes as non-hits. The extraction code now separates valid daily outcomes;
  the corrected historical denominator has not been reconstructed. Legacy JSON
  results are retained under explicit withdrawn keys for traceability.
- Describes forecast verification as a retrospective calendar-day holdout variant,
  not an issue-time operational replay. Data availability was not reconstructed;
  province-bootstrap intervals omit shared calendar-day dependence.
- Corrects the reversed visibility/extinction explanation and the treaty's legal
  status. Qualifies the ground-feed sample, unknown underlying averaging periods,
  the unvalidated >=500 screening exclusion, and differing source footprints.
- Distinguishes unweighted foreign cell-allocation proxies from weighted transport
  indices, smoke concentrations and causal source attribution.
- Extends forecast figure axes to include all frozen pairs. Removes the simulated
  delivery bar, and labels broadcast and source-share proxies explicitly.
- Replaces claims of complete statistical reproducibility and executable
  preregistration with the actual limits. The supplement now contains the
  preamble, figures, nested selected inputs and build code needed to typeset it.
  Complete raw databases/logs are not released. Figure regeneration additionally
  requires the repository fonts and plotting environment.

Primary spot checks: ASEAN treaty text and entry-into-force notice;
Lee et al. (2017), doi:10.5194/acp-17-965-2017; NOAA CPC ONI ASCII table.
Reference ledger verification varies between bibliographic metadata, abstract and
full text; this audit does not certify that all 67 sources were read in full.
