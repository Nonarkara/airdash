## Notes on things checked and found sound

- **SQL injection**: every user-facing query is parameterized; LIKE inputs escaped (`escapeLike` in api.js, same pattern in gazetteer.js:332); FTS queries quoted (`ftsQuote`, library.js:391); the only `${}` in SQL are `IN (?…)` placeholder lists, an admin-only fixed table list in `/api/health`, and integer id-lists in retention.js built from SQLite's own output. `/api/exports/:filename` is regex-anchored (`weeklyExport.js:418`) — no traversal. Static server's prefix check (`http.js:137`) correctly requires a separator boundary.
- **XSS**: frontend discipline is good — `el()` builds DOM with `createTextNode`, dynamic HTML sites use `escapeHtml` consistently (search.js, split.js, paint.js map popups); news titles and alert messages (external!) render via `el()`/textContent; chat/LLM output renders via `textContent` (chat.js:103,128). Remaining gaps are the news `href` scheme (MEDIUM above) and the unused `html:` branch (LOW).
- **Admin gating**: all FAQ/log/export-build mutating routes check `X-Admin-Token` with `timingSafeEqual` (faq.js:54–58). Feedback endpoint is deliberately public and value-validated.
- **Input validation**: `clamp()` correctly handles absent params; chat body length-capped (2 000 chars) and `readBody` enforces a 64 KB limit; `/api/patterns` validates the DOPA code with `/^\d{1,2}$/`.
- **Query/index hygiene**: the heavy scans (`/api/series/daily`, insights, sensorHealth, snapshot) are all TTL-cached in-memory with clear rationale; `idx_readings_metric_cover` covers the analytics scans; `/api/health` uses `MAX(id)` instead of `COUNT(*)`; `listExportDays` uses a skip-scan CTE. The one regression is the daily-export LIKE (MEDIUM above).
- **SW/version consistency**: `sw.js` precache URLs all exist and the `?v=2.0.0-final` suffix matches index.html (5 refs) and every JS import; cache name `airdash-v8` with correct old-cache cleanup; `/api/*` correctly never cached.
- **Scoring engines vs DESIGN-AIRDASH.md**: risk.js weights, anchors, bands, trend/stagnation thresholds, dust-season override (`dustLoadPct`/`dustSeason`/pseudo-band `low`) and washout.js curve/bands/labels/entry shape all match the contract exactly. The only inter-engine drift is danger.js's rain-relief (MEDIUM above). The in-flight causes/patterns/aq-history additions are cleanly wired (guarded `if (causes)` in `/api/risk`, validated params, cached computations) as of end of audit.
